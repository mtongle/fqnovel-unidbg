fqnovel-unidbg

基于 Unidbg 模拟番茄小说 Android 端 Native so 执行流程的 Spring Boot 后端服务。

提供搜索、目录、章节、签名、段评、图片代理等完整 API。

http://127.0.0.1:8099
✦ ✦ ✦ ✦ ✦

发现与分类

/api/fqnovel/category
GET /api/fqnovel/category/front 分类发现页
说明
返回热门分类、所有分类 Tab、下拉分类列表、Tab 内容等发现页数据。
参数
名称位置类型说明
categoryTabqueryintTab 类型（可选）
needHotquerybool是否包含热门分类（可选）
sourcequerystring来源标识（可选）
示例
curl 'http://127.0.0.1:8099/api/fqnovel/category/front'
GET /api/fqnovel/category/landing?categoryId=... 分类书籍列表
参数
名称位置类型说明
categoryIdquerystring分类 ID 必填
offsetqueryint偏移量（默认 0）
limitqueryint每页数量（默认 20，最大 50）
subCategoryIdquerystring子分类 ID（可选）
sortByquerystring排序方式: hot / new / overall（可选）
bookStatusquerystring书籍状态: serial / finish（可选）
wordNumberquerystring字数筛选（可选）
示例
curl 'http://127.0.0.1:8099/api/fqnovel/category/landing?categoryId=1&offset=0&limit=20&sortBy=hot'
GET /api/fqnovel/category/cell 分类 Cell 内容
说明
获取某个 Tab 下的更多内容区块。
参数
名称位置类型说明
newCategoryTabqueryintTab 类型（默认 0）
reqTypequeryint请求类型（默认 0）
distinctStylequeryint去重样式（默认 0）
示例
curl 'http://127.0.0.1:8099/api/fqnovel/category/cell?newCategoryTab=0&reqType=0'

签名生成

/api/fq-signature
ℹ 调用 unidbg 模拟 libmetasec_ml.so 生成 X-SS-* 签名头。
POST /api/fq-signature/generateSignature 生成签名
参数
名称位置类型说明
urlbodystring请求 URL
headerbodyobject请求头
示例
curl -X POST 'http://127.0.0.1:8099/api/fq-signature/generateSignature' \ -H 'Content-Type: application/json' \ -d '{"url":"https://api5-normal-sinfonlineb.fqnovel.com/...","header":{"Content-Type":"application/json"}}'
POST /api/fq-signature/generateSignatureWithMap Map 方式签名
说明
以 Map 格式传入 URL 和 Header 参数。
示例
curl -X POST 'http://127.0.0.1:8099/api/fq-signature/generateSignatureWithMap' \ -H 'Content-Type: application/json' \ -d '{"url":"https://api5-normal-sinfonlineb.fqnovel.com/...","headers":{"Content-Type":"application/json"}}'
POST /api/fq-signature/generateSignatureSimple 简易签名
说明
简化参数传入方式。
示例
curl -X POST 'http://127.0.0.1:8099/api/fq-signature/generateSignatureSimple' \ -H 'Content-Type: application/json' \ -d '{"url":"https://api5-normal-sinfonlineb.fqnovel.com/..."}'
GET /api/fq-signature/test 测试
示例
curl 'http://127.0.0.1:8099/api/fq-signature/test'

图片代理

/api/img
ℹ 服务端直转图片，使用设备池 Cookie/UA/Referer 获取图片，支持 HEIC→JPEG 自动转换，避免前端跨域问题。会缓存转换后的 JPEG 至内存，最大 500 张，TTL 1 小时。
GET /api/img/proxy?url=... 代理图片
参数
名称位置类型说明
urlquerystring原始图片 URL
说明
返回 JPEG 字节流。
示例
curl 'http://127.0.0.1:8099/api/img/proxy?url=https://example.com/image.heic'
GET /api/img/proxy/clear-cache 清除图片缓存
示例
curl 'http://127.0.0.1:8099/api/img/proxy/clear-cache'
